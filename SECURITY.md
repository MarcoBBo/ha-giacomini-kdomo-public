# Segnalazioni di sicurezza

Durante la fase privata, condividere eventuali problemi soltanto con il maintainer MarcoBBo attraverso un canale già concordato. Prima di una futura distribuzione pubblica andrà definito un canale riservato di segnalazione.

Non inserire in una issue password, token, email dell’account, seriali reali, indirizzi degli impianti, esportazioni .storage, header HTTP o chiavi private. Se una credenziale è stata esposta, cambiarla tramite il servizio ufficiale e seguirne le istruzioni di revoca; cancellare il testo non invalida necessariamente il token.

Le segnalazioni funzionali possono contenere versione HA, versione integrazione, comportamento atteso/osservato e diagnostica generata dall’integrazione. La diagnostica usa una whitelist priva di identità dell’account e dei dispositivi.
